**R-1 (f60f69c, test gap, medium).** No test proves that a live≠batch
divergence reaches the report as a finding. In `partition_findings`, replacing
`owner = divergence_owner(...)` with `owner = None` leaves the suite green
(66 passed with the extra). `divergence_owner` is tested only directly. Z4 never
diverges (live equals batch byte for byte), so step 3's central check has never
been seen to report anything. Needs a test that drives a divergence (e.g.
through `serve_command`) and asserts the finding and its owner. Register it for
the next series if not done now.

**R-2 (PROBES.md L2, doc, low).** L2's "Expected" is the audit's own, and its
SPEC sentence cites only the sections describing the route. spanweave-live
cddc694 §1.1 says: *"If a record's trace id cannot be had through the adapter
surface, the answer is 'no trace id' and a counted event"*. §4.2 quotes it, and
§1.5 says the same in general. §4.3 meanwhile says the receiver "invents no
event code". That tension inside the owner's spec is the strongest form of L2,
and the probe should cite §1.1/§1.5 alongside §4.3/§5.4/§8.5. Also, "no event
names it" is true of stderr but not of every output `serve` has. Verified:
`serve --deltas` on the real capture writes 5 delta lines, and the 5th has
`trace_id_after: null` and contains `concierge.conversation`, `unclaimed_record`
and `missing_trace_id` (§6.3/§8.4). L2 should say its command runs without
`--deltas`.

**R-3 (A3g reading 4, SPEC §4.3 + `spanweave_zoo/forward.py:43`, low).** The
eight-name list is attributed to RFC 9110 §7.6.1, which does not say it. RFC
9110 §7.6.1 names `Connection`, plus `Proxy-Connection`, `Keep-Alive`, `TE`,
`Transfer-Encoding` and `Upgrade`. `Trailer`, `Proxy-Authenticate` and
`Proxy-Authorization` are RFC 2616 §13.5.1's list (where `Trailer` appears as
"Trailers"). The forward also does not drop `Proxy-Connection`, and does not
drop fields named as connection-options in a `Connection` value, which RFC
9110 §7.6.1 requires of an intermediary. Fix the citation (or say the list is
the zoo's own, with the reason per name). Decide `Proxy-Connection`. Record
connection-options as a deliberate non-parse if that is the intent. The
decision is the maintainer's, because it changes what the Collector receives.
